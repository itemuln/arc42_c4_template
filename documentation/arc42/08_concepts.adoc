== Нийтлэг ойлголтууд / Cross-cutting Concepts

Олон building block-д давтагддаг дүрэм, шийдлийн зарчмыг нэг дор тайлбарлана.

=== Сонгосон нийтлэг ойлголт

БӨГЛӨХ: Authentication/access control, error handling, logging, өгөгдлийн дүрэм зэрэг өөрийн системд чухал нэг сэдвийг сонго. Хамрах хэсгүүд, мөрдөх дүрэм, хэрэглээний жишээг бич.

Бүх боломжит сэдвийг бөглөх шаардлагагүй. Давтагддаг дүрмийг нэг дор тайлбарлаж, хэрэгжүүлэх хэсгүүдтэй холбо.
