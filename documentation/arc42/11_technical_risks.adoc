== Эрсдэл ба техникийн өр / Risks and Technical Debt

Мэдэгдэж байгаа асуудал, архитектурын эрсдэл, үлдсэн техникийн өрийг ил тод тэмдэглэнэ.

БӨГЛӨХ: Мэдэгдэж байгаа асуудлыг эх сурвалжтай нь бич. Техникийн өр нь хэрэгжүүлсэн шийдлийн үлдсэн хязгаарлалт; дурын шинэ хүсэлтийн жагсаалт биш.
