== Танилцуулга ба зорилго / Introduction and Goals

Шаардлагын тойм, архитектурын чанарын гол зорилго, оролцогч талуудыг танилцуулна.

=== Шаардлагын тойм

БӨГЛӨХ: Систем ямар асуудлыг, хэний төлөө шийдэхийг 3–5 өгүүлбэрээр бич. Дэлгэрэнгүй шаардлагын баримтаа холбо.

|ID |Гол үйл ажиллагаа |Шаардлагын эх сурвалж
|FR-01 |БӨГЛӨХ |БӨГЛӨХ
|===

=== Чанарын зорилго

Хамгийн чухал 3–5 чанарын зорилгоо эрэмбэл. Төслийг хугацаанд нь дуусгах нь архитектурын чанарын зорилго биш.
