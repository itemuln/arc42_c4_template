[cols="1,2,2",options="header"]
|===
|Зорилго / асуудал |Шийдлийн арга ба шалтгаан |Дэлгэрэнгүй холбоос
|БӨГЛӨХ |БӨГЛӨХ |§5, §8 эсвэл ADR
|===

Ямар шийдэл сонгосон, яагаад тохирохыг бич. ADR бүрийн бүх түүхийг энд давтах шаардлагагүй.
