== Архитектурын шийдвэрүүд / Architecture Decisions

Чухал шийдвэрийн нөхцөл, сонгосон хувилбар, үндэслэл, үр дагавар, төлөвийг хадгална.

Доорх ADR нь бөглөх загвар. Хэрэглээгүй бол хас; шинэ шийдвэрт тусдаа ADR үүсгэ. “Санал болгосон” болон “Баталсан” төлөвийг ялга.
