Энэ бол Монгол хэл дээрх *бөглөх starter*; бэлэн системийн архитектурын тайлан биш. “БӨГЛӨХ” тэмдэглэгээг өөрийн төслийн мэдээллээр соль. Жишээ зураг бүр зөвхөн бүтэц харуулна.
====

Архитектурын баримт бэлтгэхдээ төслийн нэр, шаардлага, бодит код, шийдвэр, нотолгоонд тулгуурла. §1 нь зорилго, §3 нь системийн хил, §5 нь бүтэц, §6 нь ажиллагаа, §7 нь байрлалыг тайлбарлана. Бүх 12 хэсгийг ижил хэмжээнд дэлгэрүүлэх шаардлагагүй.

Эх файлууд `documentation/arc42/` дотор; үндсэн файл тэдгээрийг `include`-ээр нэгтгэнэ. `npm run build` HTML үүсгэж, засварласан баримтыг браузераар унших боломж олгоно. Агуулгын холбоосоор section руу үсэрнэ.
